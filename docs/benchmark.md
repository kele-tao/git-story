# Benchmark

Generated by running the real pipeline on synthetic repositories:

```bash
python benchmarks/run.py --commits 200 1000 3000
```

Python 3.12.10 on Windows-11-10.0.26300-SP0.

Raw numbers: benchmarks/results.json next to this file.

Notes:

* `scan` is dominated by the `git log` subprocess, not by Python parsing.
* `analyses` runs the classifier over every commit plus bus factor, hotspots, co-change, onboarding and the import graph.
* The HTML page embeds every chart as inline SVG and makes no network requests.
* Co-change is quadratic in files-per-commit, so it is capped at 30 files per commit: a release commit must not couple the whole repository to itself.
